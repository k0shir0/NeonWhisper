# Thrillshare-Form-Exploit
# 🛡️ CORS Misconfiguration PoC — Neon Whisper

**This repository is a vulnerability publication for security research and defensive education only.**

A proof-of-concept demonstrating how a permissive `Access-Control-Allow-Origin: *` header combined with missing authentication and rate limiting allows an attacker to spam a web form from any external origin. The demo uses only hardcoded form field IDs that were already publicly identified during an authorised blue-team investigation.
